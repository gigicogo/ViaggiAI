# APP-HTML FUNZIONANTI
Questo ramo contiene le varie versioni dell'app


- Versione 1 (viaggiai-app_ver1.html), quella descritta nell'articolo su Medium e minimale con funzionalità ridotte
è una versione basa generata con un paio di prompt, ma significativa per dimostrare le potenzialità del vibe coding

- Versione 2 (index.html), implementazione tappe di viaggio e altre funzionalità. E' la versione finale (ovvero quella in produzione su Netlify: https://viaggiai.netlify.app (può essere considerata una buona base di conoscenza, soprattutto peri prompt che ho raccolto nel ramo [/prompts](https://github.com/gigicogo/ViaggiAI/tree/main/prompts) e che possono essere usati come base per arricchire app personali un po' più evolute)
